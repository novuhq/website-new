<IntegrationSection title="Overview" icon="eye">
  The Vercel AI SDK is a TypeScript toolkit for building AI-powered applications
  and agents. It supports text generation, structured outputs, streaming, and
  tool calls.
</IntegrationSection>

<IntegrationSection title="Use it with Novu Notify" icon="refresh-cw">
  Use the AI SDK inside a Novu code step to generate, transform, classify, or
  summarize workflow content. You can also return structured output when later
  workflow steps require predictable data.
</IntegrationSection>

<IntegrationSection title="Use it with Novu Connect" icon="refresh-cw">
  Connect an agent built with the Vercel AI SDK to supported Novu Connect
  channels without replacing its models, tools, or application logic.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
For Novu Notify, install the `ai` package and your model-provider package, then call the required AI SDK functions from a workflow code step.

For Novu Connect, run:

`npx novu connect --runtime ai-sdk`

Select a supported channel and follow the CLI prompts to connect your agent.

</IntegrationSection>
