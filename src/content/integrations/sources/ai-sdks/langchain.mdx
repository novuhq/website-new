<IntegrationSection title="Overview" icon="eye">
  LangChain is a framework for building LLM-powered applications and agents with
  model, tool, retrieval, and orchestration integrations.
</IntegrationSection>

<IntegrationSection title="Use it with Novu Notify" icon="refresh-cw">
  Use LangChain inside a Novu code step to generate, transform, classify, or
  summarize workflow content with the model provider you choose.
</IntegrationSection>

<IntegrationSection title="Use it with Novu Connect" icon="refresh-cw">
  Connect an agent built with LangChain to supported Novu Connect channels while
  keeping its existing chains, tools, memory, and application logic.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
For Novu Notify, install LangChain and the model integration package you need, add your model credentials, and call the model from a workflow code step.

For Novu Connect, run:

`npx novu connect --runtime langchain`

Select a supported channel and follow the CLI prompts to connect your agent.

</IntegrationSection>
