<IntegrationSection title="Overview" icon="eye">
  A Claude Managed Agent is hosted by Novu. You bring your Anthropic
  credentials and describe the agent you want. Claude handles the reasoning.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  There's no code to host. The CLI walks you through connecting your
  credentials, creating the agent, and connecting it to a channel.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Run the command above and pick a channel. Follow the prompts to connect
  your credentials and describe your agent. You can edit it later from the
  Novu dashboard.
</IntegrationSection>
