<IntegrationSection title="Overview" icon="eye">
  Chat SDK provides building blocks for conversational applications and agent
  experiences. Novu Connect gives an existing Chat SDK application access to
  supported communication channels without replacing its core application logic.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu Connect receives channel messages, normalizes their conversation context,
  and routes them to your Chat SDK application. Responses return through the
  correct channel, thread, or conversation while Novu manages the surrounding
  communication infrastructure.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Start the Novu Connect setup flow, choose a supported channel, and configure
  the adapter that invokes your existing Chat SDK agent. Keep your current
  models, tools, and application logic in place.
</IntegrationSection>
