<IntegrationSection title="Overview" icon="eye">
  Chat SDK is an open-source chat app template built on Next.js and the AI
  SDK. You build and run the agent in your own app. Novu Connect adds the
  last step: getting it into a channel and routing replies back.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu Connect delivers channel messages to the same agent loop that powers
  your Chat SDK app, and routes its replies back to the same conversation.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Run the command above and pick a channel. The CLI adds a bridge route to
  your project. Point it at your existing agent, and you're live.
</IntegrationSection>
