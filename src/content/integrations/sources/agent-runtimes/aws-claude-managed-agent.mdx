<IntegrationSection title="Overview" icon="eye">
  The same Claude Managed Agent, hosted by Novu. You bring your AWS
  credentials instead of Anthropic's, describe the agent you want, and Claude
  handles the reasoning.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  There's no code to host. The CLI walks you through the AWS credential flow,
  creating the agent, and connecting it to a channel.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Run the command above and pick a channel. Follow the prompts to complete
  the AWS credential flow and describe your agent. You can edit it later from
  the Novu dashboard.
</IntegrationSection>
