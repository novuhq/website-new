<IntegrationSection title="Overview" icon="eye">
  The Vercel AI SDK is an open-source toolkit for building AI agents in
  TypeScript. You build and run the agent in your own app. Novu Connect adds
  the last step: getting it into a channel and routing replies back.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu Connect delivers messages from the channel to your agent and routes
  its replies back to the same conversation. Your agent keeps running in your
  own app the whole time.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Run the command above and pick a channel. The CLI adds a bridge route to
  your project. Point it at your agent, and you're live.
</IntegrationSection>
