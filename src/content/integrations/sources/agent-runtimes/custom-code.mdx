<IntegrationSection title="Overview" icon="eye">
  No framework required. The agent is fully yours: your own loop, your own
  model calls, your own tools. Novu Connect adds the last step: getting it
  into a channel and routing replies back.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu Connect delivers each channel message to your handler with its
  conversation context. Whatever your handler returns goes back to the user.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Run the command above and pick a channel. The CLI adds a bridge route to
  your project. Point the handler at your agent, and send a test message.
</IntegrationSection>
