<IntegrationSection title="Overview" icon="eye">
  A custom-code agent can use your own runtime, model provider, rules engine, or
  application framework. Novu Connect adds the communication layer around that
  agent without defining how its intelligence or business logic works.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu Connect receives messages from supported channels, preserves their
  conversation context, and forwards that context to your application. Your code
  decides how to respond, and Novu delivers the result back to the correct
  channel and conversation.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Start the Novu Connect setup flow, select a supported channel, and configure
  the bridge endpoint that invokes your agent code. Your existing models, tools,
  credentials, and application logic remain under your control.
</IntegrationSection>
