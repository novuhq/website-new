<IntegrationSection title="Overview" icon="eye">
  Sinch is a cloud communications platform that provides APIs for SMS and other
  communication channels.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu sends the content from your SMS workflow step through the Sinch SMS API
  to the subscriber's phone number.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Add your Sinch service plan ID, API token, and sender number or sender ID to
  the integration in Novu.
</IntegrationSection>
