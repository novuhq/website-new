<IntegrationSection title="Overview" icon="eye">
  Azure SMS is part of Azure Communication Services and provides APIs for
  sending text messages from applications.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu sends the content from your SMS workflow step through Azure Communication
  Services to the phone number stored on the subscriber profile.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Enter your Azure Communication Services connection string and the phone number
  used as the sender.
</IntegrationSection>
