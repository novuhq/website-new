<IntegrationSection title="Overview" icon="eye">
  Afro Message is an SMS provider for delivering text messages to customers
  across supported regions.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu sends the content from your SMS workflow step to Afro Message for
  delivery to the subscriber's phone number.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Add the Afro Message API credentials and sender ID requested by the
  integration form in Novu.
</IntegrationSection>
