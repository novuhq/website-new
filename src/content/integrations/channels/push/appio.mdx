<IntegrationSection title="Overview" icon="eye">
  App.io is a push notification provider for delivering messages to mobile
  application users.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu sends the content from your push workflow step through App.io using the
  device tokens stored for each subscriber.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Add the App.io application credentials requested by the integration form, then
  store each subscriber's App.io device token in Novu.
</IntegrationSection>
