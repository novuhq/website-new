<IntegrationSection title="Overview" icon="eye">
  Opsgenie is a Tool provider for creating alerts from Novu workflows. Each
  subscriber connects an Opsgenie API integration key, so the same workflow
  can route alerts to different Opsgenie teams or escalation configurations.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  When a workflow reaches an Opsgenie Tool step, Novu resolves the API
  integration key registered for the subscriber and creates the alert using
  the step content and configured fields. If no Opsgenie endpoint is
  registered for that subscriber, Novu skips the Tool step.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Create an API integration in Opsgenie, add Opsgenie under Tool in the Novu
  Integration Store, and register the API key as a channel endpoint for the
  subscriber. Add an Opsgenie Tool step to a workflow and send a test alert.
</IntegrationSection>
