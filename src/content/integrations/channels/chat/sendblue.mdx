<IntegrationSection title="Overview" icon="eye">
  Sendblue provides an API for sending and receiving iMessage communication from
  applications.
</IntegrationSection>

<IntegrationSection title="How it works" icon="refresh-cw">
  Novu sends the content from your chat workflow step through Sendblue to the
  phone number associated with the subscriber.
</IntegrationSection>

<IntegrationSection title="Configure" icon="settings">
  Add your Sendblue API credentials to Novu, then ensure the subscriber has the
  phone number required for iMessage delivery.
</IntegrationSection>
